# Awesome Crowd Marketing & Community Outreach

Открытый репозиторий стандартов этичного, органического крауд-маркетинга, протоколов прогрева учетных записей и методик построения естественного ссылочного профиля без санкций поисковых систем.

Курируется агентством [Антисуетологи](https://antisuetologi.ru/).

---

## Ключевые принципы антисуеты

* **Темп «Один день — одно размещение»**: естественный темп прироста ссылочной массы, не вызывающий срабатывания алгоритмов антиспама.
* **Политика нулевого спама**: запрет автоматических прогонов, синонимизированных текстов и скрытых ссылок.
* **Глубокий прогрев профилей**: минимум 14 дней отлежки и активного общения перед первой ссылочной публикацией.
* **Вечность упоминаний**: гарантия сохранности постов благодаря их высокой практической ценности для читателей форума.
